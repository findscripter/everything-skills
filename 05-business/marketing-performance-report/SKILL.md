## 何时使用

- 一次营销活动收尾，需要复盘成效、产出可转发给领导的执行摘要。
- 按周/月/季给利益相关方做渠道绩效汇总（含 QBR 季度业务回顾）。
- 手里有一堆指标，要翻译成「发生了什么 + 为什么 + 下一步做什么」。

不该用的边界：
- 只想策划/规划一场新活动 → 用活动策划类技能，本条做的是事后复盘。
- A/B 实验的设计与统计显著性判定 → 用 `ab-test-designer`。
- 从零搭建埋点/追踪/UTM → 用 `marketing-analytics-tracker`。
- 纯归因模型分析与渠道贡献拆解 → 用 `campaign-attribution-analytics`，本条只用归因辅助下结论。

开工前先确认四件事，缺什么问什么，别全套追问：
1. 报告类型：活动报告 / 单渠道报告(邮件·社媒·付费·SEO) / 内容绩效 / 整体跨渠道报告 / 自定义。
2. 时间窗：上周 / 上月 / 上季度 / 自定义区间。
3. 数据来源：能否自动拉取（已接入分析工具则先发现可用账户/平台再拉数）；若无，请用户粘贴数据——「电子表格、CSV、文字描述的看板截图，或直接给关键数字都行」。
4.（可选）对比期与读者：上一周期 / 同比；执行摘要风格 vs 分析师细节版。

## 步骤

按以下八段结构产出报告，根据报告类型裁剪指标：

1. 执行摘要：2-3 句概述本期表现；一个头条指标 + 趋势方向（涨/跌/持平 vs 上期）；一项亮点 + 一项隐忧。可独立转发给领导。
2. 关键指标看板：用汇总表呈现核心指标，状态用三色——绿(达标/超标 on track)、黄(低于目标但可接受 at risk)、红(显著低于目标 off track)。表头：`指标 | 本期 | 上期 | 变化 | 目标 | 状态`。
3. 趋势分析：周环比/月环比走势；拐点及成因；季节性/周期性规律；与基准或目标对比。
4. 成效亮点(What Worked)：前 3-5 个胜点，配具体数据 + 表现好的假设 + 如何复制或放大。
5. 待改进(What Needs Improvement)：后 3-5 个差点，配数据 + 表现差的假设 + 修复建议。
6. 洞察与观察：从指标看不出来的模式、受众行为洞察、引发共鸣的内容/创意主题、可能影响表现的外部因素（季节、新闻、竞品动作）。
7. 优化建议：每条写清「做什么 / 为什么(挂钩某条数据洞察) / 预期影响(高中低) / 实施成本(高中低) / 优先级(立即·下个冲刺·下季度)」，并用 2×2 矩阵排序。
8. 下期重点：未来周期 Top 3 优先级 + 要跑的测试/实验 + 关键指标目标值。

## 指令

- 按报告类型选指标（节选）：
  - 活动报告：曝光/触达、CTR、转化率、CPA、ROAS/ROI、总转化/注册/线索。
  - 邮件：发送·送达·退信、打开率、CTR、退订率、转化率。
  - 社媒：曝光/触达、互动率(赞+评+转/触达)、粉丝增长、CTR、爆款帖。
  - 付费：花费、曝光/点击、CTR、CPC/CPM、转化与 CPA、ROAS。
  - SEO/自然：自然会话、关键词排名变动、收录页数、外链、热门页面。
  - 内容：浏览量/独立访客、停留时长、跳出率、社交分享、内容归因转化、首尾名。
  - 整体：总线索、MQL、管道贡献、CAC、各渠道汇总。
- 建议优先级用 2×2 矩阵：

  |  | 低成本 | 高成本 |
  |---|---|---|
  | 高影响 | 立即做 | 下个冲刺规划 |
  | 低影响 | 有空再做 | 降级 |

- 输出格式：数据用表格；关键数字与趋势加粗；执行摘要短到可直接转发；用户给了大量数据时另起「详细附录」放粒度数据。
- 趋势分析需 ≥8-12 个数据点才有意义；预测一律给区间而非精确值，少于 12 点的预测标注「低置信」。
- 归因使用原则：先用末次触点（最简单可落地）；对比首/末触点理解「拉新 vs 转化」渠道；多触点优于单触点，但任何模型都只作方向参考，别据单触点孤立优化某渠道。

## 示例

关键指标看板（节选）：

```markdown
| 指标 | 本期 | 上期 | 变化 | 目标 | 状态 |
|------|------|------|------|------|------|
| ROAS | 4.2x | 3.5x | +20% | 3.0x | 绿 |
| CPA | ¥86 | ¥72 | +19% | ¥80 | 黄 |
| 转化率 | 1.8% | 2.4% | -25% | 2.5% | 红 |
```

不同节奏的模板：
- 周报（站会快扫）：Top 3 指标周环比 + 本周成效(1-2 条带数据) + 需关注(1-2 条) + 本周 3-5 个行动项。
- 月报（标准汇报）：执行摘要 → 指标看板(MoM+目标对比) → 逐渠道表现 → 活动亮点 → 成败归因 → 建议与下月重点 → 预算实际 vs 计划。
- QBR（季度战略回顾）：季度 vs 目标 → 年度走势 → 渠道 ROI → 活动汇总 → 竞争/市场观察 → 下季度战略建议 → 预算申请与分配 → 关键实验与学习。

报告交付后追问：「需要我做成可放幻灯片的摘要 / 起草给利益相关方的要点邮件 / 深挖某个指标或渠道 / 搭一个下期可复用的报告模板吗？」

## 注意事项

- 看板设计：以挂钩业务目标的指标打头，别用虚荣指标；展示趋势而非单点快照；带对比上下文（上期/目标/基准）；三色一致；按漏斗阶段或业务问题分组；控制在一屏，细节进附录；更新频率匹配决策频率（付费实时、内容每周）。
- 预测前提脆弱：短期(1-3 月)比长期可靠；外部因素（市场/竞品/经济）会让趋势预测失效，故只给区间。
- 归因陷阱：拉新渠道(展示·社媒·PR)在末次模型里永远难看，转化渠道(搜索·重定向)在首次模型里永远难看；自报归因(「你怎么知道我们的」)只作定性参考，不可当定量；跨设备/跨渠道追踪有缺口，归因数据永远不完整。
- 优化闭环：识别欠佳指标 → 定位漏斗环节 → 假设成因 → 按影响/成本排序 → 设计实验 → 测量 → 放大或迭代。测试一次只动一个变量、先定成功指标、跑满一个完整业务周期、无论成败都记录并共享（失败测试也是信息）。
