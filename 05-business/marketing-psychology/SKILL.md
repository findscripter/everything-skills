## 何时使用

当你要解释「人为什么买」、为某个营销难题挑选合适的心理杠杆、或把行为科学原理转成可执行的文案/定价/触达方案时使用。典型场景：转化率低、价格异议、建立信任、制造紧迫感、降低流失、增长停滞、决策瘫痪、引导式上手（onboarding）。

不该用的边界：
- 具体落地页的转化优化实施（CRO）——只在此处选模型，落地交给 CRO。
- 纯定价档位工程与计算——此处给定价心理原则即可。
- 从零撰写正文文案——此处给框架与措辞方向，成稿交给文案技能。
- 不要用这些杠杆做欺骗：稀缺/默认项/损失框架只在真实成立时使用，否则损害信任与品牌。

前置上下文：若仓库存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，旧版 `product-marketing-context.md`），先读它，再据具体产品与受众定制建议。

## 步骤

1. 明确目标行为：你想让用户做的**那一个**具体动作是什么。
2. 定位旅程阶段：认知 → 考虑 → 决策，不同阶段杠杆不同。
3. 识别阻碍：当前是什么在阻止该动作（摩擦、疑虑、信息缺失、动机不足）。
4. 选 1-3 个对症模型（见下方速查表），不要堆砌。
5. 解释机制 + 给出该产品的具体应用 + 标注合规/伦理边界。
6. 落地前问：是否在真实客户上验证过。

## 指令

按「难题 → 候选模型」对症下药：

| 难题 | 候选模型 |
|------|----------|
| 转化率低 | Hick 定律、启动能量（Activation Energy）、Fogg 行为模型(B=MAP)、减摩擦 |
| 价格异议 | 锚定、框架效应、心理账户、损失厌恶 |
| 建立信任 | 权威、社会认同、互惠、出丑效应(Pratfall) |
| 制造紧迫感 | 稀缺、损失厌恶、蔡格尼克效应(未完成感) |
| 留存/防流失 | 禀赋效应、转换成本、现状偏好 |
| 增长停滞 | 约束理论、局部vs全局最优、复利 |
| 决策瘫痪 | 选择悖论、默认项效应、助推理论 |
| 上手引导 | 目标梯度、宜家效应、承诺一致性 |

核心模型速记：
- 战略思维：第一性原理、待办任务(JTBD，买钻头是要洞)、能力圈、逆向思维(想"什么会必败")、奥卡姆剃刀、二八法则、约束理论、二阶思维(闪购涨收入却训练用户等折扣)、地图≠领土、杠铃策略(80%稳+20%高风险，避开平庸中间)。
- 买家心理：基本归因错误(不转化先查流程别怪人)、单纯曝光、可得性启发(用案例/证言)、确认偏差(顺着已有信念)、禀赋效应/宜家效应/零价效应(免费是质变)、双曲贴现(强调即时收益)、现状偏好/默认项、选择悖论(三档胜七档)、峰终定律、蔡格尼克(开放回路)、知识诅咒(对新人测文案)、心理账户("3元/天"≠"90元/月")、从众/社会认同。
- 说服(Cialdini+)：互惠(先给后求)、承诺一致(先要小承诺)、权威、喜好/相似("由营销人为营销人打造")、共同体、稀缺/紧迫、登门槛(小请求起步)、留面子(先报大再退让)、损失厌恶(损失约为同等收益痛感2倍)、锚定(先亮高价)、诱饵效应、框架("90%成功"vs"10%失败")、对比效应。
- 定价心理：魅力定价/左位数效应($99≈远低于$100)、整数(流畅)效应(整数显高端)、百元法则(<$100用百分比"20% off"，>$100用绝对值"$50 off")、好-更好-最好三档(中间为目标)、心理账户("$1/天"="少于一杯咖啡")。
- 设计交付：Hick 定律(一个清晰CTA胜过三个)、AIDA、七次法则(约7次触点)、助推/选择架构、Fogg(B=MAP，动机×能力×触发缺一不可)、EAST(Easy/Attractive/Social/Timely)、COM-B(能力/机会/动机)、启动能量(预填表单/给模板)、北极星指标、眼镜蛇效应(激励反噬，如推荐奖励引来薅羊毛)。
- 增长扩张：反馈回路、复利(早起步)、网络效应、飞轮、转换成本(合伦理地提高)、探索vs利用、临界质量(先深后广)、幸存者偏差(也研究失败案例)。

## 示例

场景：SaaS 试用转付费率低。
1. 目标行为：试用期内完成首个"啊哈时刻"并升级付费。
2. 阶段：决策前的考虑期。
3. 阻碍：启动能量高 + 升级有损失/后悔顾虑。
4. 选模型：启动能量(预填示例数据/模板)、目标梯度(显示"已完成80%")、损失厌恶+后悔规避(无理由退款、"随时取消")、默认项(预选推荐档)。
5. 应用：上手页给一键导入与模板降低首步摩擦；进度条制造未完成拉力；定价页用锚定(先显企业版)让目标档显得划算；加退款保证消解后悔恐惧。

场景：价格被嫌贵。
- 锚定：先展示原价/竞品价/企业档。
- 框架+心理账户：把"$90/月"重述为"$3/天，少于一杯咖啡"。
- 损失厌恶：强调"不行动会失去什么"胜过"你能获得什么"。

## 注意事项

- 一次只用少数对症模型，堆砌会互相干扰且显得操纵。
- 伦理红线：稀缺/低库存/限时只在**真实**时用；默认项用 opt-out 须合规且对用户有利。
- 沉没成本要双向用：知道何时**砍掉**不赚钱的活动，过去投入不为未来买单。
- 警惕眼镜蛇效应：上线任何激励先测试是否会被反向利用。
- 区分地图与领土：用户画像和看板是模型，别当成真实客户体验，保持与真人接触。
- 先全局后局部：优化邮件标题(局部)救不了"邮件根本不是对的渠道"(全局)。
