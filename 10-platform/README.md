# 卷十 · 平台集成（10-platform）

平台 / 三方系统 / 工具操作。对接外部系统、CLI、云、浏览器与 MCP 的技能。

**类**：`integration` 三方连接器(API/Webhook/iPaaS：Slack/飞书/Notion/Jira…) · `cli` 命令行工具操作 · `cloud` 云控制台/IaC · `browser` 浏览器自动化与网页抓取 · `mcp` MCP 服务/工具封装

> 设立缘由：评审指出 `lark-*`、`workflow-*`、各类连接器/抓取/CLI 技能在原 9 卷里 automation/backend/agents「三处抢、无处安放」。本卷给它们一个可预测的合法归属。

新增技能：在本卷下建 `skill-name/SKILL.md`，`domain` 写 `平台/<类>`。详见 [../CONTRIBUTING.md](../CONTRIBUTING.md)。
