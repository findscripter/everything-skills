Review a REST API contract with an agent

Give Codex or Claude Code the current and proposed OpenAPI specifications. Ask for breaking changes, the clients each change affects, and a migration recommendation backed by exact locations in the specifications.

Try the OpenAPI example

Which skill should I use?

  1. First choice api-design-principles. Use it for a static review of resource paths, HTTP methods, errors, pagination, and versioning. The skill includes its review guidance and examples.
  2. Alternative api-design-reviewer. Use its checklist to compare old and new OpenAPI files or structure a scorecard. The Python helpers it references are absent. Its automated review requires those files.

Recommendations reviewed on November 15, 2026. Open the interactive comparison.

Try the OpenAPI example

Two synthetic OpenAPI files demonstrate four breaking changes and four design or security findings. For example, the proposed API changes a response ID from a string to an integer. A client that expects a string could fail to parse the response or lose leading zeros.

From a checkout of Everything Skills, run the independent Node.js checker to replay the fixture comparison.

node examples/api-review/reproduce.mjs

The checker covers these fixtures. Authentication, ownership checks, and performance on a running service require separate tests.

Install the first-choice skill

Codex

With Node.js 22.20 or later, run this from the project where you want the skill.

npx skills@1.7.4 add findscripter/everything-skills --skill api-design-principles --agent codex --copy

Claude Code

Run these commands inside Claude Code to install the engineering volume.

/plugin marketplace add findscripter/everything-skills
/plugin install 02-engineering@everything-skills
