## 准入与证据

- Metadata-only admission: README/distribution, representative SKILL.md or explicit skill-infrastructure contract, source identity and license scopes reviewed. No candidate was installed, executed, cloned or copied as third-party skill body.
- Repository names, canonical URLs and available IDs deduplicated against the fetched local/main/zh union and within the daily batch.
- Independent requests verify metadata, fixed commit/tree and README, representative and license bytes against Git blob identities; partial raw responses use verified Git blob API bytes and retain correction records.
- Public task skills, routes, templates, internal maintenance files, client copies, generated exports and external provider services have distinct counting and license scopes.
- Unknown source/reuse rights and mirrored or drifted install sources remain deferred. Skill counts do not claim globally unique instructions or runtime/security/professional effectiveness.
