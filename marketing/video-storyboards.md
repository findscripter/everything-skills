# 两个短视频分镜

录制前：站点和案例须已公开并通过[检查](README.md#发布前检查)。所有演示使用公开 fixture；画面中不出现私人项目、账号通知或设备目录。下表是脚本，录屏和产物尚未据此宣称完成。

## 视频 A · 45 秒，从任务找到技能

标题：只知道任务，怎么选 Agent Skill？

| 时间 | 画面与操作 | 旁白 / 字幕 |
| --- | --- | --- |
| 0–5s | 展示检索结果和候选技能标题，随后回到搜索框 | “接手一个仓库，先用‘代码库导览’找候选技能。” |
| 5–13s | 在站点输入任务词，展示前三个结果 | “上手文档、CodeTour、综合文档，分别对应不同产物。” |
| 13–23s | 打开 `codebase-onboarding-doc`，定位 description 和工具依赖 | “先看适用范围和依赖，确认它适合这次交接。” |
| 23–33s | 展示关系区，或终端运行 `npm run skill -- why codebase-onboarding-doc` | “需要进一步写文档或 ADR，再查相关技能。关系是选择线索。” |
| 33–40s | 显示 Claude Code 协作卷安装命令；字幕另外标出 Codex 的 AGENTS.md 路径 | “Claude Code 按卷安装；Codex 从仓库文件读取。” |
| 40–45s | 干净结束卡：仓库与检索站 | “Everything Skills：任务检索、技能关系、按需使用。” |

录制证据：保存搜索词、发布 commit、真实输出截图。页面若没有已实现的关系区，用 CLI 画面，不模拟不存在的 UI。

## 视频 B · 50 秒，检查技能是否帮助完成任务

标题：找到 Skill 后，检查什么？

| 时间 | 画面与操作 | 旁白 / 字幕 |
| --- | --- | --- |
| 0–6s | 展示示例产物中的“入口 / 模块 / 运行 / 测试”小节 | “选中技能后，要看它有没有帮你产出可检查的结果。” |
| 6–14s | 打开 examples 的公开输入、环境和执行步骤 | “用同一份公开输入跟着跑，先确认环境和依赖。” |
| 14–25s | 实际运行 `node scripts/check-examples.mjs`，展示仓库案例的检查项 | “这条命令复核示例中的具体事实，不会重新运行 LLM。” |
| 25–36s | 产物与源文件并排：点击一条入口依据；检查一条运行命令 | “核对入口文件和运行命令，确保它们能回到源码依据。” |
| 36–44s | 展示真实的待确认项或检查结论；若无待确认项，展示验收表 | “缺少的事实保留为待确认；按案例的验收步骤复核。” |
| 44–50s | 结束卡：examples URL、仓库 URL | “示例步骤和边界都放在 examples，选择一个任务试用。” |

发布门槛：由案例负责人确认可用 fixture、实际产物和复跑结果后再录制。未执行前不配“成功完成”“效率提升”等字幕，不用静态模板冒充实际输出。
